# Cybergiga Kochbuch — Daten

Nur Rezeptdaten für die grok.me-Seite. **Kein** Website-Code.

- `rezepte.json` — Liste der Gerichte
- `bilder/` — ein Bild pro Gericht (relativer Pfad in der JSON)

Öffentlich absichtlich. Keine Klarname, keine Familienfotos.

Nach einem Push sind Raw-URLs etwa:

`https://raw.githubusercontent.com/<USER>/cybergiga-kochbuch-data/main/rezepte.json`

Bilder analog unter `.../main/bilder/<id>.jpg`.
